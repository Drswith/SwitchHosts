# 原生版与 5.0.2 的行为对照

基线：5.0.2 的 9 个 e2e spec（`git ls-tree -r --name-only v5.0.2 -- e2e`）。每项标注原生版的状态，并写明缺口。
状态：✅ 已实现，并有测试或实际运行验证；🟡 已实现但有待确认的部分；⬜ 未实现。

| 5.0.2 spec | 覆盖的行为 | 原生版状态 | 说明 |
|---|---|---|---|
| `local-hosts.spec.ts` | 新建本地条目、编辑内容、保存 | ✅ | 新建、重命名、编辑、`⌘/` 注释切换、行号栏（真实窗口中核对）已完成。与 Tauri 版一样自动保存（停止输入约 0.6 秒，或切换条目、失焦、关窗、退出时），没有保存按钮和 ⌘S；保存失败时显示错误提示条，此时切换条目会询问是否放弃 |
| `hosts-entry-management.spec.ts` | 增删改、移动、排序 | ✅ | 与 5.0.2 的编辑抽屉相同，一个窗口新建本地、远程、组合、文件夹四种条目（类型在新建后不可改），并编辑标题与该类型的字段；组合可选择包含的本地与远程条目，选中后只读显示所含条目；文件夹行也有开关。⌘ / ⇧ 多选后可一起移入回收站。移入回收站、上移/下移、「移动到文件夹」、拖拽（前 / 后 / 进入文件夹）均已完成，拖拽在真实窗口中核对过三种情况 |
| `folder-choice-mode.spec.ts` | 文件夹的单选/多选模式 | ✅ | 文件夹面板设置默认 / 单选 / 多选；偏好中的全局选择模式；开关规则在内核（有测试） |
| `system-hosts.spec.ts` | 系统 hosts 只读视图、历史 | ✅ | 只读视图；历史的查看、删除、清空、记录开关、上限与裁剪确认（有内核测试，并截图核对） |
| `trashcan.spec.ts` | 移入、恢复、永久删除、清空 | ✅ | 内核测试覆盖全部操作；回收站是主窗口侧栏底部的视图，详情右上为「彻底删除」与「恢复」。永久删除和清空前与 5.0.2 一样先确认；选中回收站条目会只读显示它的内容 |
| `data-transfer.spec.ts` | 导出、导入预览、失败重试、URL 导入 | ✅ | 导出、文件导入预览、URL 导入（本机 HTTP 服务验证成功与 404 失败路径）、失败后的「重试」按钮 |
| `remote-hosts.spec.ts` | 远程条目的创建、编辑、刷新、域名解析、代理 | ✅ | 创建、编辑、刷新、域名列表、DoH 解析模板（内核测试）；代理经内核测试验证 HTTP 与 SOCKS5 两种协议的路由。自动刷新间隔与 5.0.2 相同：从不、1 / 5 / 15 分钟、1 小时、1 天、7 天。四个内置 DoH 端点（阿里、DNSPod、Cloudflare、Google）经内核的 `resolve_domains`（应用批量解析所用的入口）实测，`github.com` 与 `example.com` 均得到 A 记录（一次性的真实网络检查，检查后已删除，未保留在仓库中） |
| `preferences.spec.ts` | 偏好的读写、副作用 | ✅ | 四个标签页与 5.0.2 相同：通用、命令、代理、高级。命令与运行历史、DNS、启动行为、数据目录（真实窗口中更改与重置已核对）、语言、系统窗口框架、使用数据均已实现。主题在启动时即生效；写入模式为空时打开开关会先询问写入模式；数据目录失效时启动即询问（使用默认位置、选择新文件夹或退出）。下方「有意不同」列出的设置是原生版的等价实现或不适用 |
| `titlebar.spec.ts` | 自绘标题栏 | ✅（不适用） | 原生版使用系统标题栏，该 spec 对应的功能不再需要 |

## 有意不同（5.0.2 中的设置，原生版的等价做法或不适用）

| 5.0.2 设置 | 原因 |
|---|---|
| 语言 | 提供「跟随系统」「简体中文」「English」三项，只包含中文与英文（决定）。切换后需要重新启动（`AppleLanguages`） |
| 使用系统窗口边框 | 默认关闭时隐藏标题文字、内容延伸到标题栏下方（与 5.0.2 默认外观相近），开启时使用标准标题栏。切换即时生效 |
| 轻量模式 | 原生版不提供。它是 Tauri 版为减少 WebView 内存消耗而设计的，原生版没有 WebView，不需要释放窗口内容。内核中的 `lightweight_mode` 配置键保留，Tauri 版继续使用 |
| 托盘图标快捷小窗 | 原生版不提供此开关：菜单栏项总是打开开关面板（`MenuBarExtra`，窗口样式）。原生版没有 5.0.2 的系统托盘菜单，此前的「紧凑列表」与开关面板内容相同，只差宽度，已合并。`tray_mini_window` 配置键保留，Tauri 版继续使用 |
| 发送匿名使用数据 | 开关与 5.0.2 相同，只保存配置值。5.0.2 的代码中该设置没有任何发送行为，原生版也不发送任何数据 |
| 面板的显示与宽度（左右面板） | 侧边栏的显示状态会保存（`left_panel_show`）；宽度固定为初始值 212（`NavigationSplitView` 不提供持久化用户拖动后的宽度）。1c 改版后没有右侧「信息」面板，类型、状态、行数与大小显示在详情的标题下；`right_panel_*` 配置键保留不动 |
| 查找结果的列宽 | 原生版的查找结果是列表而不是表格，没有列宽可以保存。结果行与 5.0.2 一样显示行号、匹配前后的文字，非本地条目标「只读」且不能替换 |
| 新建条目的位置 | 5.0.2 总是加到顶层；原生版在选中文件夹时加到该文件夹里，否则加到顶层 |
| 托盘右键菜单 | `MenuBarExtra` 没有右键菜单。5.0.2 托盘菜单的各项（显示主窗口、显示/隐藏 Dock 图标、版本号、退出）放在菜单栏窗口的底部。托盘图标与应用图标使用 5.0.2 的图片 |
| 顶栏 | 1c 改版后为三栏：列表栏的标题与副标题在工具栏中，详情的标题、类型、状态（含「只读」）在内容区顶部；开关在列表的每一行。启动时恢复上次的侧栏视图，首次启动选中「系统 Hosts → 当前」 |
| 侧栏文件夹的折叠 | 1c 侧栏列出所有文件夹，嵌套的按层级缩进，不再折叠；树中的 `is_collapsed` 保持原值，5.0.2 读取不受影响 |
| 关于窗口 | 使用系统标准面板（图标、名称、版本），附 5.0.2 的主页、源码链接与致谢名单 |

## 已用真实运行验证的部分

- 隔离 `HOME` 下启动签名的 `.app`：中文菜单栏、树结构、开关显示正确（截图）。
- 文件夹面板、系统 hosts 历史、查找替换的历史与「显示」定位、`⌘/` 注释切换、从本机 HTTP 服务导入备份、偏好的选择模式（截图）。
- 拖拽：子项重排、条目拖到顶层与文件夹之间均成功写入 `manifest.json`；个别顶层条目的拖拽未能用脚本复现（见上表）。
- 内核与 FFI 的端到端测试：远程刷新（`file://`）、代理（HTTP 与 SOCKS5）、HTTP API（真实 TCP）、导入导出、数据目录的校验（不写入真实的数据目录指针）。
- 原生开关在写入模式未设置时被内核拒绝，系统 hosts 未被改动。
- 数据目录的「更改」与「重置」（隔离 HOME，经 NSOpenPanel 与 NSAlert 操作）：指针文件与复制后的数据已核对，真实数据未改动。
